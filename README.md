# Code Coach · 주석 기반 인라인 코드 예시

주석과 현재 프로젝트 코드를 바탕으로 작은 코드 예시를 **흐린 글씨(고스트 텍스트)**로 제안하는 VS Code 확장입니다. `Tab`으로 수락하거나 `Esc`로 닫고 직접 코딩할 수 있습니다. 기존 0.1 버전의 댓글 말풍선은 제거했습니다. 새 창이나 별도 채팅 패널을 열지 않습니다.

## 사용하기

1. VS Code 하단 **코드 예시 OFF**를 눌러 켭니다.
2. 코드에 원하는 동작을 일반 주석으로 적고 **Enter**를 눌러 다음 빈 줄로 내려갑니다.

   ```python
   values = [-2, 3, 5]
   # 양수만 골라 평균을 구하기
   ```

3. 입력 대기와 모델 응답을 기다리는 동안 하단에 **코드 생성 중…**이 표시됩니다. 준비된 코드가 커서 위치에 흐린 글씨로 나타납니다. Enter 즉시 코드를 삽입하는 방식은 아닙니다.
4. **Tab**: 예시 반영. **Esc**: 제안 닫기. **직접 입력**: 현재 제안과 생성 요청을 취소하고 내 코드를 작성합니다.
5. 하단 **low**를 누르면 추론 수준을 바꿀 수 있습니다. 기본값은 속도와 사용량을 고려한 low입니다.

수동으로 요청하거나 새 예시를 생성하려면 주석 아래 코드 줄에서 **⌘⌥H**(Windows/Linux: `Ctrl+Alt+H`) 또는 우클릭 → **코드 코치: 주석에서 코드 예시 제안**을 실행합니다. 일부 코드를 입력한 상태에서도 수동 요청할 수 있습니다. 이미 입력한 부분은 보존하는 제안만 표시합니다.

**0.1에서 업데이트한 경우:** 작업을 저장한 뒤 명령 팔레트에서 **개발자: 창 다시 로드**를 한 번 실행하세요. 이전 말풍선 UI를 내리고 새 인라인 제공자를 적용합니다. 같은 창이 다시 로드됩니다. 이전 댓글 입력란 대신 실제 `.py` 등 코드 탭에서 사용하세요.

## 주석과 제안 범위

- Python: `# 양수 평균 구하기`, JS/TS/C 계열: `// 양수 평균 구하기`, HTML/XML: `<!-- 양수 평균 구하기 -->`처럼 독립된 한 줄 주석을 사용합니다. 연속한 주석은 최대 6줄을 함께 참고합니다.
- `# @coach ...` 형태도 지원합니다. `codeCoach.commentTrigger`를 `marked`로 설정하면 `@coach`를 쓴 주석에서만 제안합니다. 기본값 `all`은 일반 주석을 사용합니다.
- 자동 요청은 주석 아래 3줄 이내의 빈 줄에서 이루어집니다. 중간에 실제 코드를 작성하면 자동으로 다시 요청하지 않습니다. 필요하면 수동 단축키를 누르세요.
- 수동 요청은 위쪽 80줄 이내의 가장 가까운 주석을 참고합니다. 커서를 현재 코드 줄의 끝에 두어야 합니다. 커서 뒤의 기존 코드는 덮어쓰지 않습니다.
- 기본 길이 목표는 8줄입니다. `codeCoach.maxSuggestionLines`는 1~40줄 사이에서 선택하는 목표값이며, 함수·클래스·괄호를 마무리하려면 더 길어질 수 있습니다. 생성된 응답을 줄 수에 맞춰 강제로 자르지 않습니다.
- **Tab으로 수락한 뒤 Enter**로 다음 빈 줄에 내려가면 같은 주석의 의도를 유지해 이어 제안합니다. Tab 수락만으로 연속 호출하지 않습니다. 직접 코드를 입력하면 자동 이어 제안을 멈춥니다. 이어 제안 상태는 메모리에 5분간 유지되며 기능·설정 변경 시 지웁니다.
- 현재 줄 앞부분과 들여쓰기를 보존합니다. 예시는 정답 보장이 없으므로 필요한 부분을 검토하며 작성하세요.

## 모델과 추론 수준

하단 상태 표시줄의 **모델: Codex 기본** 또는 현재 모델 ID를 클릭하면 새 창 없이 모델 선택 목록이 열립니다. 코드 예시 기능이 꺼져 있어도 모델을 변경할 수 있습니다. 코드 편집기 우클릭이나 명령 팔레트의 **코드 코치: 모델 선택**에서도 열 수 있습니다.

로컬 Codex 캐시의 모델을 검색해 고르거나 **모델 ID 직접 입력…**을 사용하세요. 목록에는 현재 선택과 지원 추론 수준이 표시됩니다. **Codex 기본 모델**을 고르면 CLI 기본값으로 돌아갑니다. 선택은 저장되며 다음 코드 제안부터 적용됩니다. 프로젝트에 모델 설정이 있으면 그 설정을 갱신하고, 그 외에는 현재 VS Code 프로필에 저장합니다. 모델 변경 시 진행 중인 생성과 이전 제안 캐시는 취소·삭제합니다.

추론 수준은 low / medium / high / xhigh / max 중 해당 모델이 지원하는 값을 고릅니다. 기존 수준을 새 모델이 지원하지 않으면 캐시에 있는 지원 값으로 자동 조정합니다. 직접 입력한 모델이나 캐시에 정보가 없는 모델의 지원 여부는 생성 요청 때 확인됩니다. 계정에서 사용할 수 있는 모델은 다를 수 있습니다.

제안은 Codex CLI를 통해 생성하므로 모델 응답에 수 초 이상 걸릴 수 있습니다. 높은 추론 수준은 더 오래 걸릴 수 있습니다. 빠른 예시를 원하면 `low`를 선택하세요. 이 확장은 GitHub Copilot 구독을 사용하지 않습니다.

입력 대기는 기본 0.6초입니다. 같은 문서 내용·주석·입력 접두사·모델의 결과는 최대 5분간 16개까지 메모리에 재사용합니다. 주석 뒤에 빈 줄만 추가한 경우에도 이전 결과를 사용하며, 캐시 적중 시 추가 모델 호출은 없습니다. 관련 파일이나 설정을 변경하거나 수동 재생성을 요청하면 새로 생성합니다. 생성 중 취소한 요청은 이미 처리된 사용량이 있을 수 있습니다.

하단 상태에 마우스를 올리면 최근 생성 시간과 CLI가 보고한 입력·출력·캐시 입력 토큰을 확인할 수 있습니다. 이 값은 요청별 기록이며 누적 사용량이나 요금 계산기는 아닙니다. 결과를 재사용하면 **캐시 재사용 · 추가 모델 호출 없음**이 표시됩니다.

VS Code의 `Editor › Inline Suggest: Enabled`가 켜져 있어야 합니다. 기능이 켜져 있고 제안이 보일 때 Tab을 **Accept Inline Suggestion**에 연결합니다. 일반 편집·IntelliSense 목록·스니펫 이동·Tab 포커스 이동 중에는 이 연결을 적용하지 않습니다. 사용자 지정 키 바인딩이 우선하면 **키보드 바로 가기**에서 확인하세요.

## 프로젝트 컨텍스트

현재 파일의 **저장 전 코드**, 질문 줄, 편집기 진단, 프로젝트 파일 목록과 관련 파일 최대 2개를 참고합니다. 가까운 프로젝트 루트의 README와 구성 파일, 같은 폴더 코드와 관련 이름의 파일을 우선합니다. 커서 주변 코드는 하나의 발췌로 전달해 중복 전송을 줄입니다.

- 파일 목록 최대 800개 중 최대 30개 이름을 포함합니다. 코드 컨텍스트는 기본 6,000자입니다. 전체 프로젝트를 모두 읽지는 않습니다. 문자 수 제한은 전체 요청 토큰 수의 상한과 다릅니다.
- Downloads/Desktop/Documents에 직접 놓인 단독 파일은 현재 파일만 참고합니다.
- Downloads/Desktop/Documents를 통째로 열고 하위 프로젝트의 파일을 편집하면 첫 하위 폴더를 프로젝트 범위로 사용합니다. 예를 들어 `Downloads/train_test/dataset.py`는 `train_test` 안의 관련 코드를 참고합니다.
- Git 제외 규칙, 숨김 파일, 자격 증명 파일명, 데이터·가중치 파일과 일반 생성 폴더를 제외합니다. `codeCoach.exclude`로 추가할 수 있습니다. 소스 안 비밀 문자열을 자동 삭제하는 기능은 없습니다.
- **코드 코치: 마지막 전송 컨텍스트 확인**은 마지막 요청을 같은 창의 JSON 탭으로 보여줍니다. 기능을 끄면 요청 메모리와 캐시도 지웁니다.

## Codex 연결

설치된 `openai.chatgpt` 확장의 실행 파일 또는 PATH의 `codex`를 찾습니다. 없으면 `codeCoach.codexPath`에 절대 경로를 입력하세요. Codex CLI 0.164 계열에서 확인했습니다. 구버전에서 옵션 오류가 나면 공식 확장 또는 CLI를 업데이트하세요.

기존 CLI의 ChatGPT 로그인 인증을 사용합니다. 인증이 없다면 터미널에서 `codex login`을 실행합니다. 사용자 `config.toml`은 읽지 않으므로 사용자 지정 API 제공자와 프로필은 지원하지 않습니다. 확장이 인증 파일 내용을 직접 읽지는 않습니다.

요청은 임시 빈 폴더에서 읽기 전용·비영구 세션으로 실행합니다. 셸·앱·플러그인·훅·웹 검색·멀티 에이전트는 끕니다. 일반 코딩 에이전트의 긴 기본 지침 대신 자동완성 전용의 짧은 지침 파일을 사용합니다. **선택한 코드와 주석은 Codex 서비스로 전송되며 계정의 사용량 제한을 따릅니다.** 임시 폴더는 종료 뒤 삭제됩니다.

## 설치와 검증

`inline-code-coach-0.3.2.vsix`를 **확장: VSIX에서 설치…**로 설치합니다. 업데이트 후에는 **개발자: 창 다시 로드**를 실행해 변경 사항을 적용하세요.

### Ubuntu 서버 · VS Code Remote SSH

VS Code 1.100 이상이 필요합니다. 로컬 PC의 VS Code에서 **Remote - SSH**로 서버에 접속하고, 연결된 창의 터미널에서 실행하세요.

```sh
git clone https://github.com/Jmyeong/coding_coach.git
cd coding_coach
code --install-extension ./inline-code-coach-0.3.2.vsix --force
```

VSIX에는 실행에 필요한 JavaScript가 포함되어 있어 확장 설치만 할 때는 `npm ci`나 빌드가 필요 없습니다. `code` 명령이 없다면 연결된 창의 **확장: VSIX에서 설치…**에서 서버의 해당 VSIX를 선택하고, 확장 목록의 **SSH: 서버명** 쪽에 설치되었는지 확인하세요.

이 확장은 `extensionKind: workspace`로 실행 위치를 지정합니다. SSH 창에서는 **서버에서** Codex를 실행하고 서버의 프로젝트를 읽습니다. 서버의 같은 사용자 계정에 Codex CLI를 설치하고 로그인해야 합니다. 로컬 PC의 로그인과 모델 설정은 자동으로 옮겨지지 않습니다.

서버에 Node.js 22 이상과 npm이 준비되어 있다면:

```sh
npm install -g @openai/codex
codex --version
codex login --device-auth
codex login status
command -v codex
```

로그인 명령이 안내하는 주소를 브라우저에서 열고 인증합니다. 계정에서 장치 코드 인증을 허용해야 합니다. 설치와 인증은 [공식 Codex CLI 문서](https://learn.chatgpt.com/docs/codex/cli)와 [인증 문서](https://learn.chatgpt.com/docs/auth)를 참고하세요. Codex가 이미 서버에 설치되어 로그인된 상태라면 이 과정은 생략합니다.

명령 팔레트에서 **개발자: 창 다시 로드**를 실행하고, 작업할 프로젝트 폴더를 열어 **코드 예시 OFF**를 켭니다. 하단에서 모델과 `low` 추론 수준을 선택하세요. 서버에서는 **설정 → 원격 [SSH: 서버명]**에 다음 값을 둘 수 있습니다. 아래 경로는 `command -v codex`가 출력한 실제 절대 경로로 바꾸세요.

```json
{
  "codeCoach.codexPath": "/home/사용자/.local/bin/codex",
  "codeCoach.enabled": true,
  "codeCoach.reasoningEffort": "low",
  "codeCoach.maxContextChars": 6000,
  "codeCoach.maxSuggestionLines": 8
}
```

서버의 셸에서 `codex`가 실행되어도 확장이 PATH에서 찾지 못할 수 있습니다. 이때 `codeCoach.codexPath`를 지정하면 됩니다. 현재 구현은 Codex CLI 0.164 계열에서 확인했으며, Ubuntu 서버에서의 실제 생성은 별도로 확인해야 합니다. 오류가 나면 **코드 코치: 최근 오류 확인**에서 메시지를 확인하세요.

업데이트는 같은 폴더에서 `git pull --ff-only` 후 README에 적힌 최신 VSIX를 다시 설치하고 창을 다시 로드합니다. 소스를 수정해 다시 패키징하려면 Node.js 22 이상에서 아래 검증·빌드 명령을 실행하세요.

상태 표시줄의 **⚠ 코드 예시 ON**은 실제 요청·응답 오류입니다. 단순히 모델이 빈 응답을 준 경우에는 느낌표 대신 **ⓘ 코드 제안 없음**으로 안내합니다. 클릭 후 **다시 제안**으로 수동 재요청하거나 **켜기/끄기**로 기능을 끌 수 있습니다. 명령 팔레트의 **코드 코치: 최근 오류 확인**에서도 내용을 확인합니다.

```sh
npm ci
npm run check
npm test
npm run package
```

자동 검사는 실제 VS Code 화면에서의 Tab 입력을 대신하지 않습니다. 예시 생성은 실제 Codex 호출로 별도 확인합니다.

설정: `codeCoach.enabled`, `commentTrigger`, `maxSuggestionLines`, `model`, `reasoningEffort`, `debounceMs`, `maxContextChars`, `requestTimeoutSeconds`, `exclude`, `codexPath`.

공식 참고: [VS Code 인라인 제안](https://code.visualstudio.com/docs/editing/ai-powered-suggestions), [VS Code InlineCompletion API](https://code.visualstudio.com/api/references/vscode-api#InlineCompletionItemProvider), [Codex 비대화형 실행](https://learn.chatgpt.com/docs/non-interactive-mode).
